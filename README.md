# Satellite Telemetry Anomaly Detection & Forecasting Dashboard

A web-based interactive dashboard built with Streamlit for analyzing and detecting anomalies in satellite telemetry data.

## 🚀 Features

- Upload and visualize telemetry datasets (CSV format)
- Detect anomalies in real-time using custom algorithms
- Interactive line plots with timestamped anomaly markers
- Sidebar controls for filtering and managing data views
- Modular architecture for easy extension
